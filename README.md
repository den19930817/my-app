# Тренировочный план

Первая версия приложения: план на семь дней, добавление и удаление упражнений, отметки выполнения и общий прогресс. Данные хранятся в localStorage текущего браузера; аккаунта и синхронизации нет.

## Перенос и копирование тренировки

Выберите исходный день и нажмите «Перенести на сегодня» или «Перенести на другой день». Проверьте день назначения и подтвердите перенос. Упражнения добавятся к существующим в выбранном дне, отметки выполнения сохранятся, а исходный день освободится. Сегодня определяется по локальному времени устройства. «Скопировать со вчера» добавляет вчерашнюю тренировку на сегодня, сохраняя оригинал. В диалоге также можно выбрать копирование вместо переноса на любой день. Вес и результаты по подходам вводятся в карточке упражнения и сохраняются вместе с ним; можно записать разные веса и результаты по подходам текстом.

## Запуск

Из каталога `/workspace/my-app`:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Откройте приложение на порту 3000 в доступном интерфейсе просмотра среды. Установка зависимостей и сборка не требуются.

Демонстрационный план — пример для знакомства с приложением, а не индивидуальная программа тренировок.
